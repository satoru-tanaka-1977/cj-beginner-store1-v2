# Bookstore Portfolio / Top Page（書店サイト トップページ） [2周目]

CODEJUMP 初級編「書店サイト（トップページ）」課題の2周目の制作リポジトリです。

1周目で得た気づきや学び（デザイン全体のバランスや余白を目でしっかり確認しながら組み立てる意識）を踏まえ、より精度の高いコーディングと適切なHTML/CSS設計を目指します。

## 概要

雑誌、カタログ、アンティーク系の本を扱う本屋さんからの依頼という設定のもと、トップページのコーディングを行っています。全画面のメインビジュアル、重なり合うテキスト、背景画像上のコンテンツなど、多彩なレイアウトを実装します。

## コーディング仕様

- **フォント指定**: 
  `Arial`, `Hiragino Sans`, `Hiragino Kaku Gothic ProN`, `Meiryo`, `sans-serif` の順
- **コンテンツ幅**: 
  - コンテンツ最大横幅: 1200px（左右パディング: 5%）
  - メインビジュアルのみ全幅表示
- **メインビジュアル**: 
  - 全画面表示（高さはブラウザの高さに合わせて可変）
  - 右上にロゴを配置
- **Archive / New**: 画像の上に網掛けのテキストを重ねて配置
- **Fashion & Style**: 全幅表示させた背景画像の上にテキストとボタンを配置
- **Catalog / Antique**: グレー背景の上に画像とテキストを横並びで配置
- **フッター**: ロゴとテキストのエリアを3分割にして横並びに配置
- **レスポンシブ**: ブレークポイント 896px

## 制作上のポイント（2周目の取り組み）

- 単に数値を合わせるだけでなく、デザイン全体の見た目やバランスを目で確かめながら実装する。
- 適切なHTMLタグの選定（セマンティックHTML）と、メンテナンス性の高いCSS構造を意識する。
